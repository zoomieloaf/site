Getting started

Free. Or from the terminal:

code --install-extension zoomieloaf.margin

  1. Install Margin from the VS Code Marketplace or Open VSX.
  2. Open any .md file and click Open in Margin in the editor title bar.
  3. Press Ctrl+E (Cmd+E on macOS) to switch between reading and editing.
